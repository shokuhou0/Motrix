# 批量命名下载（Windows 定制开发版）

基于 Motrix v2.0.0-beta.39。此源码包不是已经生成的安装包。

## 使用方式

在“新建任务”的链接输入框中粘贴，每行一个任务：

```text
xxx01,https://example.com/a.mp4
第02集$https://example.com/b.mp4
自定义名称.mkv，https://example.com/c.mp4
https://example.com/d.mp4
```

前三项分别保存为 `xxx01.mp4`、`第02集.mp4`、`自定义名称.mkv`，第四项保留原来的自动命名方式。

- 支持英文逗号 `,`、中文逗号 `，` 或美元符号 `$`。只将第一个分隔符作为名称与链接的分界；完整链接内的符号保持不变。每组名称和链接放在同一行，不要手动换行（输入框自动折行不影响）。
- 名称中不能含上述三种分隔符，不能是路径，也不能包含 Windows 文件名非法字符或设备保留名。
- 名称没有扩展名时，仅从网址路径的末尾提取扩展名；不从查询参数推断，也不访问服务器探测。
- 无法推断扩展名时保留输入名称。下载地址本身不会解码或改写。
- 磁力链接保持原有使用方式，不支持“名称,磁力链接”。
- 存在无效行时标出行号并阻止整个表单提交，修正后再下载。
- 每行名称优先于高级选项中的文件名。混合批量中的普通链接保持自动命名。
- 重名冲突沿用 Motrix 原有处理；本修改不增加覆盖或去重规则。

## Windows 下载与验证

定制分支的工作流同时构建安装版和免安装 ZIP。构建成功后，在 GitHub Actions 中下载所需产物：

- `Motrix-Batch-Windows-x64`：解压后运行安装程序。
- `Motrix-Batch-Windows-x64-NoInstall`：解压下载文件，再解压其中的程序 ZIP，运行 `Motrix.exe`。请保留完整程序目录。设置和任务记录仍使用正常的 Windows 用户数据目录。

工作流执行代码检查、解析器和表单测试、原生组件测试、添加任务端到端测试、打包检查与启动测试；还会解压免安装 ZIP，检查并启动解压后的程序。某一步失败将阻止产物交付。这些是 fork 中未签名的开发版，不是官方发布。验证通过不代表每一个第三方下载地址都可访问。

定制版仍使用上游应用标识和数据目录。官方更新可能覆盖此功能；安装或替换现有 beta 前请保留原安装包及数据备份。此开发版没有代码签名，不能当成官方发布版。
